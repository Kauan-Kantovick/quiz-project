📌 O que é?
O VibeCoder Quiz é uma aplicação web interativa criada para avaliar o nível de dependência de Inteligência Artificial durante o processo de programação .

Através de perguntas objetivas e situações comuns de desenvolvimento de software, o sistema calcula uma porcentagem que representa o quanto o usuário se aproxima do perfil conhecido como Vibe Coder.

Ao final do questionário, o participante recebe um diagnóstico acompanhado de recomendações para melhorar suas habilidades técnicas e desenvolver maior autonomia na programação.

🤖 O que é um Vibe Coder?
O termo Vibe Coding descreve uma abordagem de desenvolvimento em que o programador utiliza Inteligência Artificial como principal ferramenta para gerar código .

Nesse modelo, o usuário descreve o que deseja em linguagem natural e a IA produz parte ou até mesmo todo o código necessário para implementar a solução.

Embora essa prática tenha se tornado cada vez mais comum com a popularização das IAs generativas, existem discussões sobre seus benefícios e riscos para o aprendizado e para a qualidade dos projetos desenvolvidos.

🎯 Objetivo do Projeto
O principal objetivo do VibeCoder Quiz é conscientizar os desenvolvedores sobre a forma como utilizar ferramentas de Inteligência Artificial durante a programação .

O sistema não busca demonizar ou proibir o uso de IA, mas incentivar um uso mais consciente, responsável e educativo dessas ferramentas.

Ao final do quiz, o usuário receberá:

📊 Seu percentual de Vibe Coding;
🏷️ Uma classificação baseada nas respostas fornecidas;
💡 Recomendações personalizadas para aprimorar suas habilidades;
📚 Dicas para usar IA como ferramenta de apoio, e não como substituto do aprendizado.

📖 Proposta de Aprendizado
Este projeto foi idealizado como uma oportunidade de aprendizado prático para os membros da equipe.

A proposta inicial é desenvolver a maior parte da aplicação utilizando apenas os conhecimentos adquiridos pelos integrantes, incentivando:

Raciocínio lógico;
Pesquisa;
Resolução de problemas;
todo de programação;
Autonomia no desenvolvimento.

O uso de Inteligência Artificial poderá ser planejado e autorizado pela equipe em situações específicas, desde que exista consenso entre os participantes e que a ferramenta seja utilizada como apoio ao aprendizado,
e não como substituição do desenvolvimento realizado pelos membros.
